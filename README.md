# MITS Gwalior Homepage Replica

A responsive, student-made homepage replica inspired by **Madhav Institute of Technology & Science (MITS), Gwalior**. The project is built as a single static HTML file for front-end development practice.

> **Disclaimer:** This is an educational project and is **not the official MITS website**.

## Features

- Responsive layout for desktop, tablet, and mobile
- Sticky navigation bar
- Mobile navigation menu
- Hero section with call-to-action buttons
- Latest updates ticker
- Academic and campus feature cards
- About section with institute statistics
- Notices and announcements section
- Academic departments grid
- Admissions call-to-action
- Footer with quick links and contact information
- Smooth scrolling and hover effects
- Embedded image assets for simple deployment

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Flexbox
- CSS Grid
- Media Queries

## Project Structure

```text
mits-gwalior-homepage/
├── index.html
└── README.md
```

The CSS, JavaScript, and main image assets are included directly inside `index.html`.

## Run Locally

### Option 1 — Open directly

Download the repository and open:

```text
index.html
```

in any modern browser.

### Option 2 — Use a local server

From the project folder:

```bash
python -m http.server 5500
```

Then open:

```text
http://localhost:5500/
```

## Deployment

This static website can be hosted using **GitHub Pages**.

Go to:

```text
Repository → Settings → Pages
```

Select:

```text
Source: Deploy from a branch
Branch: main
Folder: / (root)
```

After deployment, the site can be accessed at:

```text
https://himanshu051116.github.io/mits-gwalior-homepage/
```

## Purpose

This project demonstrates responsive web design, semantic HTML, modern CSS layout techniques, basic JavaScript interaction, and static-site deployment using GitHub Pages.
